# My Personal Site

A personal site built for Hack Club's Stardance program, a space to showcase things i like my projects, or just me!

Demo: https://jiujiu-dot.github.io/my-personal-site/?v=2

## What you can find? 

- Cool (i think) minecraft layouts and style MADE ALL BY ME
- What i like to do, what i already made like my art and more
- EVERYTHING U NEED TO KNOW ABOUT ME :D 

## Tech Stack

- **HTML** — page structure and content
- **CSS** — styling and layout
- **JavaScript** — swipe gallery interactivity and layout rendering logic

## Project Structure

```
my-personal-site/
├── index.html      # main entry point
├── style.css        # site styling
├── script.js         # interactivity 
```

## Running Locally

1. Clone the repo:
   ```
   git clone https://github.com/jiujiu-dot/my-personal-site.git
   ```
2. Open `index.html` directly in your browser — no build step or server required.

## Status

In active development. Currently doing a final bug pass, adding personal touches, and polishing details before calling it shipped.
